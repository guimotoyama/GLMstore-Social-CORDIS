Seu site demora?

Você já otimizou imagem, ativou cache, comprimiu tudo — e o site continua demorando para abrir. O gargalo pode estar onde você menos procura: no servidor.

O TTFB é o tempo que o servidor leva para devolver o primeiro byte. Antes dele, nenhuma imagem carrega. E é esse número quem dita o teto do LCP, uma das métricas que o Google usa na busca.

A referência vem do HTTP Archive: sites com TTFB abaixo de 200 ms têm 3,2 vezes mais chance de passar em todos os Core Web Vitals. Em hospedagem compartilhada, a média fica entre 400 e 800 ms sob carga.

Salve este post para revisar quando o site engasgar. E, se quiser entender o que o seu servidor está fazendo com o seu site, fale com a gente.
